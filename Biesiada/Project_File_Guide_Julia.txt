Project File Guide

0. Data Cleaning
Prepares the SkillCorner tracking data for analysis. It converts the nested player and ball data into clean tables and connects player IDs with names, teams, and positions.

1. Simple Tracking Animation
Creates a basic animation showing how the players and ball move during a selected part of a match.

2. Exploratory Data Analysis
Explores the passing data to understand the types of passes players choose, the options available to them, and the defensive pressure they face.

3. Building the PTR Dataset
Creates the Passing Threat Reduction metric and builds the main possession level dataset used in the project.

4. PTR Validation
Checks whether the PTR metric works correctly and whether it produces reasonable results across different defensive situations.

5. Spatial Features
Uses tracking data to add information about player positioning, defender pressure, team shape, passing lanes, and distances on the field. (More advanced)

6. Variable Selection
Selects the variables used in the models and removes variables that are unnecessary, repetitive, highly correlated, or could create data leakage.

7. XGBoost Model
Builds and evaluates the XGBoost model that predicts whether a player selects the highest threat realistic passing option.

8. Midfielder Results
Compares midfielders’ actual passing decisions with the decisions expected by the model and identifies different passing styles.

9. Presentation Animation
Creates an animation of a selected passing situation for use in the final presentation.

10. PTR Situation Visualization
Creates field diagrams comparing the pass selected by the player with the more threatening passing option that was available.
